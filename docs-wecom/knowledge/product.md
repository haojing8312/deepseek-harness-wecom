# 企微销冠工作台

## 产品简介

企微销冠工作台（WeCom Top-Sales Workbench）是基于 DeepSeek Harness 构建的企业微信客户服务与销售助手平台。它接入企业微信 PC 客户端，自动接收外部客户的微信消息，由 AI 智能体理解并回复，帮助企业高效维护客户关系。

## 核心功能

- **自动回复**：收到客户消息后，AI 自动生成并发送回复，无需人工逐条处理。
- **客户会话管理**：每个客户的消息自动归入独立的持久化会话，重启后仍能续接上下文。
- **知识库问答**：内置只读知识库，AI 回复产品/业务问题时基于知识库内容，保证准确。
- **连接监控**：实时显示企微通道连接状态（在线/离线/连接中）。
- **配置管理**：可在设置中配置企微客户端路径、注入参数、自动回复与限速策略。

## 技术架构

- 底座：DeepSeek Harness（插件化 agent harness）。
- 接入：通过 vworkApi.dll 注入企业微信 PC 客户端（固定版本 5.0.3.6005），建立本地 HTTP 双通道。
- 智能体：每个客户会话使用受限的"客户 preset"，仅开放回复与只读知识库两个工具，确保外部消息不可触达系统内部。

## 客户数据与安全

- 客户消息与回复全量记录在本地会话日志，支持审计。
- 客户智能体无法访问文件系统、命令行或内部网络。
- 提供全局急停、客户白名单与消息限速，防止误操作与刷屏。
