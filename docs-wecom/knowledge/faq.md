# 常见问题（FAQ）

## 这是什么产品？

企微销冠工作台是企业微信上的 AI 客户服务助手，自动接收并回复外部客户的微信消息。

## 会自动回复吗？

会。收到客户消息后，AI 会自动生成并发送回复，无需人工逐条操作。支持全局急停与消息限速。

## 客户消息安全吗？

安全。客户消息由受限的专用智能体处理，它只能回复消息和查询只读知识库，无法访问你的文件、命令行或内部系统。所有消息与回复都记录在本地日志。

## 会话会丢失吗？

不会。每个客户的会话都会持久化保存，即使重启服务，客户再次发消息仍能接续之前的上下文。

## 支持多账号吗？

当前版本支持单企业、单账号接入。多账号支持在规划中。

## 如何配置？

在 Web 设置页面的"企微销冠工作台"卡片中，可以配置企业微信客户端路径、注入参数、自动回复开关与每客户限速。

## 遇到连接问题怎么办？

在 Web 界面查看连接状态。若显示离线，确认企业微信客户端已安装并登录（固定版本 5.0.3.6005），然后重启服务。
